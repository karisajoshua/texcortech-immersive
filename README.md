# Texcortech Immersive

Immersive 3D website for Texcortech Systems.

## Stack
Next.js · TypeScript · React Three Fiber · Three.js · Drei · GSAP

## Development
```bash
npm install
npm run dev
```

## Direction
The experience is built as scroll-driven digital storytelling. The initial procedural scene validates WebGL, motion, responsiveness and performance before production 3D assets are introduced.
